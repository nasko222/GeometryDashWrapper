Geometry Dash Wrapper 0.9.5-endurancetest11
Verification and uploaded-log diagnosis

RUNTIME STATUS
--------------
The new invalid-ground fallback and legacy first-play decoder prime were not
executed on Windows in this environment. They remain targeted runtime tests,
not confirmed fixes. The user confirmed EnduranceTest10 fixed the moving black
editor region; that code is preserved unchanged in this source.

UPLOADED LOG DIAGNOSIS
----------------------
1. Selected 2.2 beta invalid ground
- The run reports the EnduranceTest10 asset limits, then reaches the defensive
  SpriteBatchNode blend hook with atlas->texture equal to null.
- The log terminates on that exact event. The numeric selector clamp therefore
  did not cover every community selector entry.
- Supplying blend factors alone cannot repair the half-built atlas because
  initWithTexture continues after updateBlendFunc.

2. Legacy ARM music
- StereoMadness is started twice in the same run.
- No wrapper volume command occurs between attempt 1 and attempt 2.
- Both attempts replay the same already-open MCI alias. This points to the MCI
  decoder/device's first-start state rather than another explicit volume write.

ENDURANCETEST11 CHANGES
-----------------------
1. Missing 2.2 ground texture
- If the exact blend hook observes a null texture while the editor is active,
  it asks the beta's own CCTextureCache to load packaged
  groundSquare_01_001.png.
- It installs that valid CCTexture2D through CCTextureAtlas::setTexture before
  SpriteBatchNode::initWithTexture resumes.
- Valid textures retain the exact host reproduction of updateBlendFunc.
- The confirmed editor-background suppression, BPM path, selection rendering,
  culling and Practice Z/X code are unchanged.

2. Legacy first-attempt music
- Only legacy ARM enables this policy.
- A newly opened non-looping MCI alias is played muted for 100 ms, stopped,
  rewound, and restored to its queried MCI volume before the real play command.
- The prime occurs once per opened alias. Menu loops are excluded.
- No persistent first-play volume override or frame-by-frame volume guard is
  introduced.
