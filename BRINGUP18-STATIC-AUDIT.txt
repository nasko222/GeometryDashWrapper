Observed Bringup17 failure
--------------------------
- End screen failed in cocos2d::CCString::floatValue with R0=0.
- Fault address: 0xfffffff4.
- The same fault repeated before the wrapper reported FAILED.
- Bringup18 adds a narrow recovery only for null/underflow faults while PC or LR
  is inside CCString::floatValue; unrelated guest faults remain fatal.

Hook execution policy
---------------------
- libgame.so is mapped and relocated.
- Its constructors are run before nativeInit.
- The wrapper calls only named ApplyHooks groups selected by safe/all profile.
- HookManager::do_hook is handled by the host wrapper and redirects references
  in the primary ARM image.
- libhooking.so and libdobby.so are inventoried but not executed.
- loader() is not called, preventing an uncontrolled duplicate all-hook pass.
- Dynarmic guest code cache is cleared after hook installation.
