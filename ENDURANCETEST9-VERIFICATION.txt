UPLOADED LOG DIAGNOSIS
----------------------
- The EnduranceTest8 BPM path completed through
  LevelEditorLayer::levelSettingsUpdated().
- The editor-only updateCameraBGArt replacement executed, but the user observed
  that the black wrapped background region continued moving. EnduranceTest9
  anchors the three actual editor background nodes at fields 0x498/0x49C/0x4A0.
- The failing ground/background run entered __dynarmic_v22_batch_update_blend
  with a valid batch object (0x3197B3A0). The nested guest helper subsequently
  reached texture offset 0x54 with R0=0 and faulted.
- Exact selected-APK disassembly shows updateBlendFunc is four field operations:
  batch+0x108 -> atlas, atlas+0x48 -> texture, texture+0x54 -> PMA, and
  batch+0x10C/+0x110 -> blend source/destination. EnduranceTest9 performs those
  operations host-side and uses normal non-PMA blending if texture data is absent.
