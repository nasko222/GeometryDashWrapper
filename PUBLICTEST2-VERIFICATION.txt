Important binder correction
----------------------------
Geometry Dash 1.0 uses a legitimate 32-bit dyld bind-stream address wrap. A
64-bit segment-offset accumulator rejects this stream as an impossible huge
address. PublicTest2 deliberately performs the bind offset arithmetic at ARM32
pointer width, matching the target process.

Regression isolation
--------------------
- x86 backend tree is byte-for-byte identical to PublicTest1.
- shared audio/network/storage/song/runtime source is byte-for-byte identical.
- legacy ARM backend differs only in the displayed PublicTest2 profile version.
- Android ARMv7 backend differs only in the displayed PublicTest2 profile version.
- IPA execution is routed to a separate ios-armv7 backend.

Compile/static verification
---------------------------
The new iOS backend passes local C++20 syntax checking with:
  -Wall -Wextra -Werror
using a Dynarmic interface stub matching the APIs used by the existing wrapper.
