UPLOADED LOG DIAGNOSIS
----------------------
1. x86 v1.50 rejects every editor shortcut in tweaks12 with:
   "Editor controls: key ignored; GameManager has no active editor".
   The GameManager editor hard gate is therefore invalid for this family.

2. 2022/2023 restored editors get through EditorUI creation but fail when Play
   first uses native Cocos arrays. Logs show CCArray::removeAllObjects reaching
   ccArrayRemoveAllObjects with a null internal array, and another 2023 run
   reaches ccArrayDoubleCapacity -> realloc with the same null native structure.

3. Preview variable 0036 is definitely observed in the uploaded 2023 run (both
   state=0 and state=1 appear), so the remaining visual bug is transition/refresh
   behavior rather than a missing toggle observer.

TWEAKS13 CORRECTIONS
--------------------
- Removed tweaks12's x86 GameManager editor hard gate.
- EditorUI positive/negative lookup is cached per actual running Cocos scene.
- Retained hidden-EditorUI guard so editor shortcuts stay disabled in Play.
- Retained exported CCDirector::getRunningScene when available.
- Added CCDirector::drawScene-based running-scene-offset derivation for older
  x86 Cocos builds where getRunningScene is inline/not exported. The available
  older x86 test ELF resolves the derived running-scene field to +0x6C.
- ARM editor CCArray reuse now validates native ccArray storage, count/capacity,
  and backing element pointer before accepting an inherited object shell.
- CCArray data offset is profile-specific: +0x20 in 2019, +0x30 in 2022/2023.
- Added the missing 2019 editor Play collection at LevelEditorLayer+0x2A4.
- Preview 0036 transitions now receive an 8-editor-frame native background grace
  window on both ON and OFF transitions.
- Preview animation/particle refresh callbacks run on the next editor frame.
- Host editor opacity no longer forces normal 70-alpha dimming while Preview is on.
- The tweaks12 dual GameManager gameplay/editor pointer slots remain intact.
