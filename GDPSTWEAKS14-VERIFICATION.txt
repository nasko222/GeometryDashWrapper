PROVEN ARM CORRECTION
- 2019 lib (9,144,004 bytes): CCArray::initWithCapacity stores native ccArray at object+0x20.
- 2022 lib (9,541,500 bytes): stores it at object+0x30.
- 2023 lib (9,578,364 bytes): stores it at object+0x30.
- 2019 `CCArray::objectAtIndex`: loads native pointer from object+0x20, then element array from data+0x08 (12-byte inner structure).
- 2022/2023 `CCArray::objectAtIndex`: loads native pointer from object+0x30, then element array from data+0x0C (16-byte inner structure).
- Tweaks13 used data+0x08 for every profile. Tweaks14 selects 12/+0x08 for 2019 and 16/+0x0C for 2022/2023.
