UPLOADED ENDURANCETEST4 LOG DIAGNOSIS

1. Practice hotkey safety regression
- Z was dispatched directly to UILayer::onCheck in the uploaded ARMv7 run.
- No Practice Mode flag was checked before the callback.
- EnduranceTest5 checks the exact selected-beta PlayLayer byte at +0x29A0.
- Normal Mode now logs DYNARMIC_PRACTICE_HOTKEY_IGNORED and invokes no callback.

2. Editor object/BPM regression
- The uploaded log contains 28 DYNARMIC_V22_EDITOR_GRID_REFRESH events.
- The guessed playtest state repeatedly changes from active=1 to active=0 on adjacent frames.
- EnduranceTest4 therefore called LevelEditorLayer::updateGridLayer repeatedly.
- EnduranceTest5 removes every host updateGridLayer call.
- Per-frame updateMusicGuideTime, periodic updateTimeMarkers and editor-session reset remain.

3. Right-side black region
- EnduranceTest4's pre-render scissor/viewport sanitizer did not resolve it.
- The uploaded run contains no successful clip-reset event despite the region appearing.
- EnduranceTest5 rolls the sanitizer back and leaves guest GL state authoritative.
- The right-side black region remains OPEN and is not claimed fixed.

4. Legacy Z/X ABI
- Audited 1.0/1.4-era ARM binaries export no-argument UILayer::onCheck() and
  UILayer::onDeleteCheck(), not only the newer CCObject* sender variants.
- They also export PlayLayer::getPracticeMode() and PlayLayer::getUILayer().
- EnduranceTest5 resolves both callback ABIs and uses both accessors.

5. Legacy attempt-to-attempt music volume
- A single setaudio command immediately after MCI play was not sufficient.
- EnduranceTest5 reasserts the stored volume for 45 active rendered frames after
  play, resume, rewind, seek/replay or an explicit volume change.
- Runtime log marker: Audio MCI volume guard active: volume=... frames=45
