Geometry Dash Wrapper 0.9.5-unified7-fix4-native-stabilization
Verification and supplied-log analysis
============================================================

Scope
-----
This is a stabilization/source build. It removes the Python launcher/build
requirement, fixes the exact ARMv7 startup argument failure found in logs.zip,
fixes x86 dated-log routing, preserves the x86 network implementation that the
user confirmed restored Geometry Dash 2.1 internet, and keeps the focused
render/input/legacy-ARM changes from the previous source.

Evidence from supplied logs.zip
-------------------------------
- 25 dated launches were present.
- Every Geometry Dash 2.2/SubZero ARMv7 attempt stopped before nativeInit with:
    ERROR: --companion-hooks must be off, safe, or all
  The launcher had supplied a value the backend rejected. Fix4 defaults the
  backend to companion hooks OFF and does not pass that option from the launcher.
- The dated x86 folders contained run-info.txt but no gd-wrapper.log. The x86
  backend changes its current directory before opening its historical fixed log
  name, while the old launcher searched only the distribution root. Fix4 passes
  an absolute --log path and the x86 backend resolves it before changing CWD.
- Geometry Dash 1.8, 1.90 and 1.93 each later completed at least one run with
  exit code 0. They are therefore not classified as globally unsupported.
- Earlier failures included intermittent access violations (0xC0000005) and
  1.8 exits of 0xCFFFFFFF, but the missing x86 backend logs prevent a responsible
  root-cause fix in this source revision.
- Geometry Dash 1.0 reached constructors/JNI/OpenGL and then faulted during
  nativeInit at the CCSet vtable address. Geometry Dash 1.01 completed.
- Official 2.11 Boomlings account login is not patched because the same legacy
  login fails in the Android emulator; GDPS behavior remains selectable.

Implemented changes
-------------------
1. Native launcher, no Python
   - src/launcher/native_launcher.c parses the APK ZIP and binary manifest,
     selects x86/legacy ARM/ARMv7, creates dated log folders, sets environment
     variables and launches the backend.
   - run_auto.py and build_x86.py are absent.
   - BUILD_LAUNCHER.cmd/build_launcher.ps1 build GeometryDashLauncher.exe.
   - BUILD_ALL.cmd builds all backends and the native launcher.

2. Separate launch entry points
   - RUN_AUTO_GDPS.cmd uses naskogdps17.7m.pl/database.
   - RUN_AUTO_BOOMLINGS.cmd uses www.boomlings.com/database.
   - Either BAT accepts an APK dropped onto it; otherwise it uses game.apk.

3. ARMv7 2.2 startup
   - Companion hook default is Off.
   - The parser trims whitespace/quotes and reports the received invalid value.
   - The native launcher omits --companion-hooks entirely.
   - Direct desktop-GLSL compatibility and guest-owned editor viewport/scissor
     behavior from Fix3 are retained; the companion ShaderFix experiment is not.

4. x86 network and logging
   - The x86 runtime and song HTTP implementation are byte-for-byte the Fix2
     versions associated with the confirmed Geometry Dash 2.1 network recovery.
   - Absolute --log paths are accepted before the x86 backend changes CWD.
   - Each run can now contain the actual gd-wrapper.log needed for account
     backup/load and intermittent crash investigation.

5. Legacy ARM 1.0
   - Exact 1.0 library detection remains scoped by size and CRC.
   - Forced-HD and host-minizip acceleration are disabled only for this exact
     library, retaining guest fallback and leaving 1.01+ unchanged.
   - This is a targeted attempt and still requires a real Windows runtime test.

6. Readability
   - The new launcher is extensively commented for C#/Java developers.
   - docs/CODE-TOUR-FOR-CSHARP-JAVA-DEVS.md explains ownership, structs,
     pointers, cleanup and the three backends.
   - Established emulator cores were not mass-refactored because doing so would
     add regression risk. Comments/documentation do not alter generated code;
     actual bug fixes necessarily alter the affected binaries.

7. Packaging
   - No .gitignore is included.
   - No APK, extracted game .so, EXE, DLL, Python source, .pyc, __pycache__,
     build cache or save data is included.
   - A real multi-resolution Meltdown icon is included.
