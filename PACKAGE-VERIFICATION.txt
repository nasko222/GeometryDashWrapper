Scope
- Separate Dynarmic ARMv7 branch for the supplied Geometry Dash 2.2 betas.

- Release and source archives contain no APK or extracted game native library.

Runtime regression addressed
- Bringup11 installed six companion editor hooks before editor creation.
- The supplied log then exhausted 500,000,000 guest ticks in
  __vmi_class_type_info::__do_upcast while LevelEditorLayer::create was active.
- Bringup12 removes the complete ApplyHooks path and restores Bringup9's
  targeted LevelEditorLayer::create + LevelEditorLayerExt::initH sequence.
- Bringup11 also replaced valid non-empty level setups with catalog data.
- Bringup12 preserves valid guest setups and uses the APK catalog/latest inflate
  only to recover an empty or unreadable setup.
- The Bringup11 COW-release experiment was removed from the repair path.
