Geometry Dash ARM wrapper 0.9.4-arm-v22beta-bringup13

Scope
- Separate Dynarmic ARMv7 branch for the supplied Geometry Dash 2.2 betas.
- Stable Dynarmic Test14-fix1 source for Geometry Dash 1.0-1.4 was not modified.
- Release and source archives contain no APK or extracted game native library.

Runtime changes
- Guest C-string operations now have a mapped-memory-bounded 64 MiB ceiling.
  The former 1 MiB ceiling truncated Press Start (1,241,094 decoded bytes) and
  Knock Em Out (1,091,308 decoded bytes).
- LevelEditorLayer and PlayLayer each receive only their companion
  updateVisibility helper. Complete ApplyHooks groups remain disabled.
- Space/Up queue button 1 directly; left/right retain buttons 2/3.
- WAV effects use a 48-slot waveOut backend. Music remains on MCI.
- Valid non-empty level setups and the targeted editor initH path are preserved.
