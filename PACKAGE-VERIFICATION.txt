Geometry Dash ARM wrapper 0.9.4-arm-v22beta-bringup14

Scope
- Separate Dynarmic ARMv7 line for the supplied Geometry Dash 2.2 betas.
- Stable Dynarmic Test14-fix1 for Geometry Dash 1.0-1.4 was not modified.
- Release and source archives contain no APK or extracted game native library.

Evidence and changes
- Log 17 stopped after editor entry because the companion visibility helper
  scanned all 10,000 editor sections in emulated ARM every frame.
- Log 18 inflated the test platformer successfully, then crashed in companion
  GDPSManager::detectEmulators through __stack_chk_fail.
- Editor visibility now uses a bounded native CCArray scan and primary game
  object functions, with at most 32 new activations per frame.
- PlayLayer runs its untouched primary visibility implementation first; a
  native post-pass sets only platformer-control opacity.
- Companion GDPSManager, full ApplyHooks, constructors, DPAD touch hooks,
  collision hooks, and broad gameplay hooks remain disabled.
- Bringup13 level decoding/recovery, large strings, input, music, and waveOut
  sound effects are preserved.
