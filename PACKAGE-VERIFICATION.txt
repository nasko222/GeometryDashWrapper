Geometry Dash ARM wrapper 0.9.4-arm-v22beta-bringup15

Scope
- Separate Dynarmic ARMv7 line for the supplied Geometry Dash 2.2 betas.
- Stable Dynarmic Test14-fix1 for Geometry Dash 1.0-1.4 was not modified.
- Release and source archives contain no APK or extracted game native library.

Evidence and changes
- Log 19 shows host A/D delivery but no editor movement; Bringup15 routes
  editor playtests through EditorUI and gameplay through UILayer.
- Native UILayer canvas-touch state enables mouse jump only after the game's
  own pause/control hit testing.
- F2 directly opens My Levels through CreatorLayer::onMyLevels.
- Companion editor helpers are optional and capability-gated. Only the
  validated selected-beta CRC/layout may run targeted initH and visibility
  bridges. Missing or unknown helpers continue with the primary game image.
- Early-layout APKs receive a native editor callback bridge.
- Empty level setup recovery adds GJGameLevel vtable validation, compatible
  field scanning, official-song fallback, and non-fatal native passthrough.
- Full companion ApplyHooks, constructors, GDPS, DPAD, collision, and broad
  gameplay hooks remain disabled.
