  construction, rather than only unsupported community selector entries.

  visibility path is therefore present; it should not be replaced by a global
  texture substitution.

  Stereo Madness play, yet the user still heard attempt 2+ louder. That
  experiment is therefore removed.

ENDURANCETEST12 CHANGES
-----------------------
- Removes LoadV22FallbackGroundTexture and all packaged-ground substitution.
- Adds a guest-side entry guard around CCSpriteBatchNode::initWithTexture:
  valid textures tail-call the untouched original function; a null texture
  returns false through a host diagnostic before any node fields are mutated.
- Keeps the exact host updateBlendFunc field implementation for valid nodes.
- Keeps the 18-ground/26-background native-asset clamps as a first line of
  defense, while the entry guard safely handles any remaining unsupported path.
- Removes the legacy muted/waiting/stopping decoder-prime implementation and API.
- On legacy ARM only, the first non-looping play of each freshly opened music
  alias receives one immediate `play ... from 0` second-start command. It makes
  no volume change and does not stop, mute, wait, or rewind between the two
  starts. This directly reproduces the state transition observed on attempt 2.
