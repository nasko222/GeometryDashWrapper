Geometry Dash Wrapper 0.9.6-gdpsfixes1 verification
===================================================
Branch: gdpsfixes1

Scope
-----
This branch is Android-only. The abandoned experimental platform backend, its
launcher path, build target, packaging path and its public-test notes are absent.
The remaining runtime families are x86, legacy ARM and ARMv7.

Implemented fixes
-----------------
1. Critical >4095-byte upload formatting bug
   PASS: legacy ARM FormatGuestString dynamically re-renders values larger than
         its 4096-byte stack scratch buffer.
   PASS: ARMv7 FormatGuestString has the same fix.
   PASS: the old branch that appended strlen(temporary) after snprintf reported
         a larger required size is absent from both backends.
   PASS: focused C++ regression with a 72,000-byte level-style %s value:
         old_level_bytes=4095, new_level_bytes=72000, new_full=yes.
   NOTE: the existing 16 MiB FormatGuestString safety ceiling remains intact.

2. Background-music retry / StartPos seek compatibility
   PASS: shared audio backend has one stop-before-seek helper.
   PASS: play, stop, resume-from, rewind and set-time routes use that helper.
   PASS: seek order is stop -> set time format -> seek -> optional play.
   EXPECTED: Wine/Proton no longer receives a seek command while the MPEG alias
             is actively playing, which was the reported MCI error-277 case.

3. Slow/unreachable GDPS networking
   PASS: legacy ARM nonblocking connect returns guest EINPROGRESS immediately.
   PASS: legacy ARM nonblocking recv returns guest EAGAIN immediately.
   PASS: the previous 15-second select path remains only for guest sockets that
         are actually blocking.
   NOTE: ARMv7 already used nonblocking pending-connect semantics; x86 already
         has its own asynchronous/synthetic API connection path.

Not claimed fixed in gdpsfixes1
-------------------------------
- Original Geometry Dash Android 1.0.0 background-color/BG-trigger crash.
  A verified 1.0.0 vs 1.0.1 native-binary comparison is required first.
- Editor WASD/Q transform shortcuts. Historical wrapper testing proves that the
  tempting EditorUI::keyDown route is unsafe on Android; a verified transform
  callback/object ABI is required before enabling this across versions.
- Cursor hiding and pause-button removal are intentionally excluded.

Environment limitations
-----------------------
Windows/Wine runtime execution was not available in this environment.
The complete ARM translation units were not compiled here because the Dynarmic
SDK/header tree used by the Windows builder is not installed in this session.
The long-format regression harness was compiled and executed locally with g++.
Therefore upload/audio/network behavior still requires the real Windows/Wine
wrapper test before release to users.

Priority runtime test order
---------------------------
1. Upload a level whose encoded data is comfortably over 4095 bytes (20-50 KB
   is ideal), download it again, and verify its ending/object count is intact.
2. GD 1.0: die and retry several times; music must restart from the beginning.
3. GD 1.0: add a StartPos, verify correct music timestamp, then press Restart.
4. Throttle/disconnect the GDPS and use Search; the UI must not sit in a
   ~15-second synchronous connect wait.
