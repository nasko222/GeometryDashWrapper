# Source contents — 0.9.7-cof5

Included:

- unified native launcher and Windows build scripts;
- x86, legacy ARM, and ARMv7 backends based on the clean COF2 behavior;
- shared Windows audio/network/storage/runtime bridges;
- shared `FPS=VSYNC` / numeric QPC frame-pacing implementation;
- EnduranceTest10/companion ARMv7 2023 editor handling retained from COF2;
- GDPS/account/save/network and desktop support code;
- project source and third-party licenses.

Not compiled into COF5:

- the retired stock 2019/2022/2023 wrapper-built editor reconstruction;
- the COF3/COF4 Geometry Dash 1.02 comments-hotkey experiment.

No APK, IPA, proprietary game `.so`, built EXE/DLL, or save data is included.
