# Source contents — v22beta Bringup7

The archive contains the complete wrapper source tree, Windows build scripts, pinned dependency preparation, raw ARMv7 `libcocos2dcpp.so` probe input, and current Bringup7 documentation.

No APK files are included. An APK passed to `BUILD_V22BETA_X64.cmd` is copied only into the generated local `dist-arm-wrapper-v22beta-bringup7` directory.
