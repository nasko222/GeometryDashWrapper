GeometryDashWrapper 0.9.7-newera9 verification notes
======================================================

User evidence used
------------------
Latest supplied ARM 1.1 run: launcher newera8, package com.robtopx.geometryjump,
version 1.1. The first-attempt preservation succeeds. After pause/stop, the
first editor-placement touches fail in strlen with guest pointer 0x210.
newera8 logged its stop as detached-retained-cleanup0, so cleanup=false did not
eliminate the crash.

Changes under test
------------------
1. Post-play placement crash:
   - no removeFromParentAndCleanup call on normal playtest stop
   - hidden PlayLayer remains attached to the scene
   - PlayLayer and its UILayer are touch/keypad disabled when exports exist
   - player/UILayer/PlayLayer actions and selectors are stopped
   - PlayLayer update is unscheduled
   - visual root is hidden, not removed
   - GameManager play-layer pointer and patched guest code are restored
   - retained temporary level/PlayLayer are intentionally parked

2. Dotted line:
   - square.png is treated as 16 Cocos points in the HD asset scale, not 32
   - X scale uses length / 16 with 10% overlap
   - applies to both green breadcrumb and orange trajectory segments

3. Trajectory:
   - cube/ball trajectory snapshots an airborne launch and remains in world
     coordinates instead of being re-anchored every frame
   - anchor resets on landing, gravity change, mode change, or teleport-sized
     position discontinuity
   - ship/UFO guide is hidden because a ballistic extrapolation without input
     state is misleading
