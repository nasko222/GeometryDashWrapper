NETWORKTEST7 ROOT-CAUSE BASIS
=============================

NetworkTest6 successfully retired synthetic import trampolines and continued
through CRYPTO_zalloc and CRYPTO_strdup. Its final two completed worker imports
were both inside CRYPTO_THREAD_run_once, and no DNS/socket call followed.

That means the previous problem was no longer only a bad saved import PC. The
remaining failure was still inside the emulated ARM pthread/libcurl/OpenSSL
stack. Repeatedly changing worker scheduling was no longer a useful direction.

NetworkTest7 bypasses that entire stack at CCHttpClient::send. It preserves the
game-facing CCHttpRequest/CCHttpResponse ABI and callback behavior, but uses a
real host WinHTTP thread for transport.
