Geometry Dash Wrapper 0.9.6-gdpstweaks4 verification
===================================================

Static/source verification only; Windows gameplay runtime is not available in this environment.

- DPI awareness helper is called by launcher, x86, legacy ARM and ARMv7 before game-window creation.
- Per-Monitor-V2 is attempted first; older Windows fallbacks are present.
- gdpstweaks3 forced GL_NEAREST -> GL_LINEAR magnification rewrite is removed on all three backends.
- REMOVE_PAUSE_BUTTON exists in both launch CMDs and defaults false.
- HIDE_CURSOR_WHEN_PLAYING exists in both launch CMDs and defaults false.
- x86 pause removal uses derived UILayer field + CCNode::setVisible(false).
- legacy ARM pause removal uses game CCNode::setVisible(false).
- ARMv7 pause removal uses game CCNode::setVisible(false).
- all three backends block only the top-right gameplay pause touch target when enabled.
- all three backends preserve Escape/Android Back pause behavior.
- cursor suppression is Win32 client-cursor suppression and is gated by gameplay state.
- Extras runtime remains disabled.
