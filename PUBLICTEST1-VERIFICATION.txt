Geometry Dash Wrapper 0.9.6-publictest1
PublicTest1 verification

SCOPE
-----
PublicTest1 adds a read-only IPA analyzer to the native launcher. It does not execute iOS code yet.
The existing APK backend selection/runtime path is intentionally kept on the EnduranceTest12 baseline.

IPA ANALYZER
------------
- Detects .ipa before entering the Android launcher workflow.
- Finds the root Payload/<app>.app/Info.plist member.
- Parses both XML and binary plist metadata.
- Finds CFBundleExecutable, with app-name/largest-top-file fallbacks.
- Parses thin and fat Mach-O headers, ARMv6/ARMv7/ARMv7s/ARM64/x86/x86_64, LC_MAIN, dylib imports and encryption commands.
- Reports ARM32 as reusable with the current A32 Dynarmic CPU core, but explicitly stops before iOS execution.
- Does not attempt to bypass encrypted App Store executables.

REGRESSION BOUNDARY
-------------------
- Complete x86 backend is byte-identical to EnduranceTest12.
- Shared audio/network/storage/song sources are byte-identical to EnduranceTest12.
- Legacy ARM and ARMv7 source differ only in their displayed version strings.
- InitializeLauncherContext, which performs the established APK scan/metadata/backend selection/save/log setup, is byte-identical to EnduranceTest12.
- The only launcher routing change outside the analyzer is an early .ipa branch in wmain.

HOST-SIDE FIXTURE TEST
----------------------
A portable C harness compiled with GCC and successfully parsed:
- a Python plistlib-generated binary Info.plist;
- an XML Info.plist containing the same RobTop-style metadata;
- a synthetic 32-bit ARMv7 Mach-O executable with LC_MAIN and a UIKit dylib import.
This validates the new parsers independent of the Windows launcher plumbing.
