NETWORK FIX
-----------
NetworkTest2 already used asynchronous native DNS, nonblocking Winsock sockets, and a frame-sliced guest HTTP worker. The freeze log showed that one Dynarmic JIT run could remain inside translated guest work long enough that the normal post-Run tick/time checks never regained control.

NetworkTest3 keeps those mechanisms and adds a per-Run 4 ms host wall-clock watchdog. If the run does not return, a separate host thread calls Dynarmic HaltExecution(kCallbackHalt). The guest CPU state remains resumable on the next frame slice; the request is not converted back to DynarmicTest14's synchronous/blocking worker.
