Geometry Dash Wrapper 0.9.6-gdpsfixes7 verification
===================================================

Source/static verification performed in the packaging environment.
Windows/Dynarmic runtime execution was not available here.

1.3 GDPS legacy-v7 startup
--------------------------
PASS: legacy ARM includes Dynarmic ExclusiveMonitor.
PASS: legacy ProbeEnvironment now implements MemoryWriteExclusive8/16/32/64.
PASS: exclusive writes use compare/exchange semantics identical to the existing
      ARMv7 ProbeEnvironment implementation.
RATIONALE: the supplied 1.3 GDPS log stalls at an LDREX/STREX retry loop in
           libascella.so constructor #1; gdpsfixes6 had the monitor but lacked
           the callbacks required for STREX to commit.

Extras rollback
---------------
PASS: normal/generated RUN scripts no longer set EXTRAS_MENU=true.
PASS: gd_settings_extras_menu() is hard-disabled.
PASS: gd_extras_menu_init() cannot enable the feature even if an old environment
      still contains EXTRAS_MENU=true.
PASS: ARMv7 fixes5 scene-tree Extras overlay/pointer interception was rolled back.
PASS: no RefreshSceneTreeState or gd_extras_menu_pointer_event path remains in
      the ARMv7 backend.

2.2 beta platformer controls
----------------------------
PASS: gameplay/editor-playtest state is checked before editor hotkey suppression.
PASS: editor playtest WASD/Space continues through LevelEditorLayer queueButton.
PASS: mouse platformer ownership uses the live LevelEditorLayer during playtest
      instead of the stale GameManager PlayLayer pointer.
PASS: editor playtest has a mouse-jump fallback when no usable UILayer exists.

2.2 beta editor save/exit regression
------------------------------------
PASS: ARMv7 editor/scene lookup is restored to pre-fixes5 behavior.
PASS: fixes5 scene-tree traversal and injected Extras nodes are absent from
      editor teardown/save paths.
NOTE: the supplied crash log requested a nonsensical 1,062,567,949-byte guest
      allocation while inside nativeTouchesEnd; this was not normal heap
      exhaustion. Runtime retest is required to confirm the rollback removes it.

Packaging
---------
PASS: no APK, IPA, .so, EXE or DLL payload is present in the source tree.
