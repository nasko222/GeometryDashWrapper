Fixes4 test evidence -> Fixes5 corrections
-------------------------------------------
1. Extras UI
   - Fixes4 used a native Win32 BUTTON / TrackPopupMenu UI.
   - PASS: shared Extras implementation contains no CreateWindowExA BUTTON,
     TrackPopupMenu, CreatePopupMenu, or AppendMenu path.
   - PASS: legacy ARM, x86, and ARMv7 build Extras visuals from game/cocos nodes:
     ButtonSprite controls plus a CCLayerColor overlay.
   - Host hit-testing only activates the injected cocos controls; clicks consumed by
     the Extras overlay are not forwarded to the underlying game menu.

2. Placeholder level
   - The previous raw GJGameLevel::create() path produced an empty level.
   - Actual early Android libgame.so disassembly of LevelTools::getLevel(int):
       0x001a95c8: cmp r3, #0x0a
       0x001a95ca: bls jump-table
     Therefore IDs 0..10 are handled by the real built-in level table; only >10
     takes the fallback path.
   - PASS: Play Placeholder Level now calls LevelTools::getLevel(10).
   - PASS: background music suppression remains enabled for the placeholder run.

3. Time Machine Beta
   - Supplied Fixes4 GD 1.02 log shows PlayLayer::scene reached the artificial
     100,000,000 guest-tick guard after only about 66.3 ms; another extras scene
     construction reached about 100,000,768 ticks after about 50.7 ms.
   - This proves the failure was the wrapper scene-call tick ceiling rather than a
     failed LevelTools::getLevel(8) lookup.
   - PASS: PlayLayer::scene and CCDirector::replaceScene Extras transitions now use
     unlimited guest ticks (tick_budget=0) with a real 15-second wall-clock watchdog.
   - PASS: Play Time Machine Beta continues to use built-in level ID 8 on exact GD 1.02.

4. Editor shortcuts
   - Supplied Fixes4 logs contain zero successful DYNARMIC_EDITOR_COMMAND dispatches.
   - The previous guessed-object-field EditorUI detector was therefore not reaching
     the real editor UI.
   - PASS: Fixes5 discovers MenuLayer / PlayLayer / LevelEditorLayer / EditorUI through
     the live cocos scene and CCNode child arrays, with a GameManager fallback where
     appropriate.
   - PASS: a dropped shortcut is now logged explicitly as no-active-EditorUI.
   - PASS: no backend routes these shortcuts through EditorUI::keyDown.
   - Controls:
       W/A/S/D         move
       Shift+W/A/S/D   larger move
       Q               rotate counter-clockwise
       E               rotate clockwise
   - Legacy/x86 sender command tags: move 1..8, rotate 11/12.
   - ARMv7 2.2 direct EditCommand values: move 1..8, rotate 0x13/0x14.
