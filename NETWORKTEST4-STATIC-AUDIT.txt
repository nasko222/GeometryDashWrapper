NETWORKTEST4 STATIC AUDIT
=========================

Result: PASS

Preservation
------------
- 21 runtime source files compared against NetworkTest3.
- 20 runtime source files are byte-for-byte identical.
- The only changed runtime source is src/dynarmic_probe.cpp.
- No APK is included in the source tree.

Network correction
------------------
- sem_post advances the foreground PC and immediately pumps the worker.
- condition signal/broadcast advances the foreground PC and immediately pumps
  the worker.
- The worker state is saved/restored around the pump.
- The 4 ms asynchronous Dynarmic HaltExecution watchdog remains enabled.
- Asynchronous DNS and nonblocking socket implementations remain present.

Forensic diagnostics
--------------------
- 512-entry fixed import ring records every imported call.
- Every relevant thread/sync/network import logs call and return details.
- Long root guest calls emit 250 ms heartbeats.
- Calls >=250 ms dump the last 128 imports after returning.
- Watchdog and failure paths dump the last 128 imports.
- Request-like Android logs emit a request marker before worker/socket activity.
- Import manifest includes real runtime index, SVC, stub address, group and name.

Syntax
------
- Complete C++20 translation unit: PASS.
- Only three pre-existing unused-private-field warnings.

Limitations
-----------
A Windows x64 executable could not be linked in this environment because the
source archives do not contain the pinned compiler executable and full Windows
dependency headers. The source is prepared for BUILD_V22BETA_X64.cmd on the
existing Windows build machine.
