2026-08-27 LOG DIAGNOSIS
------------------------
1. 2019 stock beta
- Tweaks15 reaches DYNARMIC_V22_WRAPPER_EDITOR_INIT_OK and DYNARMIC_V22_LEVEL_EDITOR_ENTERED.
- The first editor nativeRender faults in LevelEditorLayer::draw() with R0=0.
- Exact 9,144,004-byte disassembly shows draw() loads LevelEditorLayer+0x444 and immediately calls CCArray::count().
- The same draw function also uses LevelEditorLayer+0x298 as a CCArray in its group-overlay path.
- Tweaks16 adds/revalidates +0x444 and +0x298, while retaining the exact 2019 onPlaytest array +0x2A4.

2. 2023 stock beta
- The editor reaches a live restored state and Preview variable 0036 is observed enabled.
- Play still faults in ccArrayDoubleCapacity -> realloc(nullptr, 0).
- Exact 9,578,364-byte onPlaytest disassembly uses LevelEditorLayer+0x354 for removeAllObjects/addObject.
- Tweaks16 revalidates the critical Play collection after full init and before every editor touch/render boundary, rather than only during the early construction pass.

3. Song line / BPM guidelines / Preview
- Current tweaks15 retained the old per-frame song/BPM updater, but the new logs never report DYNARMIC_V22_DRAW_GRID_FOUND / SONG_GUIDE_FRAME / TIME_MARKERS_REFRESH.
- The historical known-working editor run did report DrawGrid discovery, song-guide frame 1, and time-marker refresh frame 2.
- Tweaks16 caches the DrawGrid object at creation and first resolves the exact per-profile DrawGrid field (2019 +0x4E8, 2022 +0x2C54, 2023 +0x2C88).
- Exact levelSettingsUpdated() disassembly confirms it consumes only already-restored level/grid/settings fields.
- Preview flag observation was already alive; tweaks16 reapplies the native preview animation/particle callbacks after levelSettingsUpdated() if Preview is already enabled.
