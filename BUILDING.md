# Building EnduranceTest7

Run `BUILD_ALL.cmd` on Windows with the pinned Zig 0.14.1, CMake 3.31.10,
Ninja 1.13.2 and Dynarmic revision configured by the included build scripts.
Python is not required.

The source archive intentionally contains no APK or prebuilt game library.
After building, drag the desired APK onto `RUN_AUTO_GDPS.cmd` or
`RUN_AUTO_BOOMLINGS.cmd`.
