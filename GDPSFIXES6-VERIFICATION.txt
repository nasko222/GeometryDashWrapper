Geometry Dash Wrapper 0.9.6-gdpsfixes6 verification
===================================================

Scope
-----
This branch is a compatibility expansion from gdpsfixes5. Existing supported APK
routing and gameplay code are intentionally left unchanged unless the APK has the
new v7-packaged legacy-libgame shape.

Launcher routing regression
---------------------------
PASS: x86 remains first priority when an x86 game library exists.
PASS: lib/armeabi/libgame.so still routes to legacy ARM exactly as before.
PASS: lib/armeabi-v7a/libcocos2dcpp.so still routes to the ARMv7/2.2 backend.
PASS: lib/armeabi-v7a/libgame.so without libcocos2dcpp now routes to legacy ARM.
PASS: a 2.2 APK that contains both libcocos2dcpp.so and an auxiliary libgame.so
      still selects ARMv7, not the new legacy compatibility mode.

Legacy-v7 compatibility implementation
--------------------------------------
PASS: legacy backend first tries lib/armeabi/libgame.so, preserving old behavior.
PASS: it falls back to lib/armeabi-v7a/libgame.so only when the old path is absent.
PASS: v7-packaged legacy games run the same legacy runtime with Dynarmic ARMv7
      architecture enabled, rather than entering the 2.2-specific backend.
PASS: an ExclusiveMonitor is configured for ARMv7 exclusive-memory instructions.
PASS: additional v7 .so files are considered companions only when they are ELF
      modules and reference/depend on libgame.so.
PASS: auxiliary modules are mapped beginning at guest 0x18000000, below wrapper
      object memory and separate from the primary game image.
PASS: auxiliary relocations resolve defined symbols locally, game/cocos symbols
      against the primary image, and remaining imports through the existing host
      import bridge.
PASS: primary constructors + primary JNI_OnLoad execute first; companion constructors
      + companion JNI_OnLoad execute before nativeSetPaths/nativeInit.
PASS: hybrid-only dlopen/dlsym can resolve mapped game/companion symbols.
PASS: AEABI memcpy/memmove/memset/memclr helpers used by modern ARM companions are
      implemented in the legacy import bridge.
