TWEAKS15 CORRECTIONS
--------------------
- IsUsableV22CcArray now rejects capacity zero for editor collection fields. A real CCArray::create/init path always starts with capacity >= 1, so zero-capacity shells are rebuilt instead of surviving until Play.
- The profile-specific native layouts remain intact: 2019 object+0x20/elements+0x08; 2022/2023 object+0x30/elements+0x0C.
- Early2019 builds a packaged sprite-frame index from APK sprite-sheet plists. During the narrow EditorUI::create fallback window, only frame names proven absent from that APK bypass the expensive guest spriteFrameByName dictionary lookup. Packaged names still execute the untouched stock lookup, and a stock null still retains the original fallback path.
- Early2019 missing-frame diagnostics log the first 32 unique names plus summaries rather than flushing once for every missing frame.
- The early fast-fallback Thumb thunk was independently assembled; its literal loads and branch opcodes were checked against Clang/LLVM output. The final fallback literal load is 0x4B05.
